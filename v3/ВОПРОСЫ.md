# Вопросы по заданию (v3)

Для каждого вопроса я выбрал самое буквальное чтение задания и продолжил работу.

1. **Папка измерителя.** В задании сказано `ЯДРО-ОПЫТ\бенч`, а на диске лежит `ЯДРО-ОПЫТ\bench` (`bench.jsonl` + `build_bench.py`,
   создан 2026-10-07 в 15:56, судя по всему исполнителем v1). Набор по смыслу общий для всех вариантов, поэтому беру `bench`
   как есть и ничего в нём не меняю. Новую папку `бенч` не создаю, иначе у вариантов было бы два разных измерителя.

2. **Где работать.** Сессия открыта в `C:\ВОЕНКОМАТ ПРОЕКТ НАВЗВАНИЕ НЕ ПРИДУМАЛ\ядро\Claude`, то есть внутри рабочего проекта.
   Задание же говорит: «Твоя папка: `ЯДРО-ОПЫТ\<номер>` рядом с рабочим проектом», а из рабочего проекта «можно ТОЛЬКО ЧИТАТЬ».
   Поэтому работаю в `C:\ЯДРО-ОПЫТ\v3`, а в `...\ядро\Claude` ничего не пишу.

3. **Можно ли блоку разбора определять область?** Блок разбора обучен и записывает в значение типа «Разбор» поле `область`.
   Ядро передаёт это значение тому блоку, у которого в паспорте вход `Разбор` с условием `область = X`. Вопрос: не считается ли
   это «обученным классификатором в роли маршрутизатора», который запрещён?
   Моё чтение: запрет относится к ядру. В ядре нет ни одного обученного числа, а его правило выбора такое: сравнить поле значения
   с условием из паспорта, выбор однозначен, конфликтующий блок ядро не подключит. Решение об области — это выход
   блока разбора, то есть часть «разбора вопроса» из примера в задании. Оно видно в следе и в отчёте меряется отдельно как
   «ошибка блока разбора». Если такое чтение неверно, есть другой путь: отдавать «Разбор» всем блокам областей и выбирать
   ответ по фиксированному правилу. Но тогда каждому блоку области пришлось бы уметь говорить «не моё», а для этого
   нужны данные, которых нет.

4. **Вопросы не по теме.** В типе `Область` всего два значения: {здоровье, право}. Значения «вне темы» нет: в измерителе таких
   вопросов нет, а чистых данных «вне обеих областей» в проекте тоже нет (`ood_train*` — это вопросы о призыве, которых нет
   в Расписании болезней, и многие из них правовые). Значит, вопрос не по теме блок разбора отправит в одну из областей.
   Отказ «не знаю» сейчас срабатывает только тогда, когда для нужной области не подключён блок.

5. **Какой монолит брать для сравнения.** В задании сказано: «одна модель, обученная целиком на тех же данных». Беру ту же
   семью моделей, что у блоков (линейная модель как у fastText: мешок признаков → вектор → классы). Вход — сырой текст
   (основы слов, пары основ и куски слов по 3–5 букв), выход — 132 класса (88 статей + 44 правовые темы), обучение на
   объединении всех данных, на которых учились блоки. Чтобы разобрать причины потерь, дополнительно обучаю
   «монолит на основах»: на вход ему идёт ровно то, что проходит через тип «Разбор». Это добавка к сравнению, а не замена.

6. **Что такое «первый ответ».** Это верхний вариант ответа. Ответ «не знаю» засчитывается как неверный.

7. **Чем заменить блок области на шаге 5.** «Обученным заново отдельно» читаю так: новый файл весов, другое зерно случайности
   и другое устройство сети (со скрытым слоем вместо линейной), обучение отдельным процессом. Типы и остальные блоки
   при этом не трогаются.
