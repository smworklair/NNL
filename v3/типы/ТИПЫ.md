Источник правды — `типы.json` и `словарь.txt`. Их записал скрипт `собрать_типы.py` 2026-10-07 в 16:09:26, до обучения

Ядро сверяет `типы_sha256` в паспорте каждого блока с текущим `типы.json`. Блок, обученный под другие типы, ядро не подключает.

## Типы
| тип | что это | поля |
|---|---|---|
| `Текст` | вопрос человека как он есть | строка |
| `Разбор` | вопрос, сведённый к словарю типа | `область` ∈ Область; `p_область` — вероятность для каждой области; `основы` — основы значимых слов вопроса в порядке текста, только из СЛОВАРЯ; `замены` — [слово, основа, p] для слов, которых не было в словаре (для следа) |
| `Ответ` (конечный) | ответ области | `область`; `id` ∈ Ответы[область]; `p` ∈ [0,1]; `кандидаты` — до 5 пар [id, p] |

На вход блок может поставить условие по полю-перечислению: например, `Разбор[область=здоровье]`.
Двух блоков с одинаковым входом (тип + условие) ядро одновременно не держит.

## Эталонное правило «текст → основы» (`канон.py`)
1. Нижний регистр, «ё» → «е».
2. Слово — непрерывный кусок из русских/латинских букв и цифр.
3. Служебные слова из фиксированного списка выбрасываются. «не», «нет», «без» остаются.
4. Основа — стеммер Snowball для русского (snowballstemmer 3.1.1).
5. Эталонный разбор = основы, которые есть в СЛОВАРЕ.

Блоки областей учатся на эталонном разборе своих обучающих вопросов, то есть без блока разбора. Блок разбора обязан
выдавать значения этого же типа. Встречаются блоки только при работе, внутри цепочки, которую строит ядро.
