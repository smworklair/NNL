# Продолжение работы без ноутбука (на 20.10.2026)

## Что где живёт

| Что | Где | Как обновить |
|---|---|---|
| Приложение (Next.js, Telegram Mini App) | `военкомат/app` → https://spravka-app.vercel.app (проект `spravka-app`) | `cd военкомат/app && vercel deploy --prod --yes --name spravka-app --scope smworklairs-projects` |
| Python-ядро NNL (API) | `военкомат/ядро_api` → https://nnl-api.vercel.app (проект `nnl-api`) | `python военкомат/ядро_api/собрать.py --проверить`, затем `cd военкомат/ядро_api/dist && vercel deploy --prod --yes --name nnl-api --scope smworklairs-projects` |
| «Моё дело» (SQL) | Neon Postgres `spravka-delo`, схема `военкомат/app/db/schema.sql` | `node --env-file=.env.local db/migrate.mjs` (после `vercel env pull .env.local`) |
| Старый сайт (HTML/JS) | `военкомат/макеты` → https://spravka-godnost.vercel.app | пока смотрит старый Mini App `spravka`; можно отключить после переключения |
| Бот и Mini App | Telegram `@nll_voenkom_bot`, настройка через `@BotFather` (`/newapp`, `/editapp`) | токен лежит только в Vercel (`TELEGRAM_BOT_TOKEN`) и у BotFather |

Приложение берёт ядро по `/api` (rewrite в `app/next.config.ts`, адрес в переменной `NNL_API`, сейчас `https://nnl-api.vercel.app`).
`/api/delo` обслуживает само приложение (SQL), остальное уходит в Python.

## Что есть только на ноутбуке (не в git)

- `C:\KEY CLAUDE\KEY.txt` — ключи Groq, Gemini, Qwen (нужны только для внешних моделей и бенчмарков, не для сайта). Сохранить в менеджере паролей.
- `NNL/диалог/журнал_работы/` — рабочий журнал (в `.gitignore`).
- `военкомат/app/.env.local` — восстанавливается: `vercel env pull .env.local` в папке `app`.
- `военкомат/app/node_modules` — восстанавливается: `npm install`.

## Что можно делать без ноутбука

- Править интерфейс и данные: репозиторий + Claude Code в облаке; каждая правка выкладывается командой `vercel deploy` из `военкомат/app`.
- Telegram, BotFather, база Neon (веб-панель Vercel → Storage), токены (Vercel → Settings → Environment Variables) — всё из браузера.
