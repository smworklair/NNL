# Справка по годности (voenkomat)

Приложение для призывников: найти свою болезнь в Расписании болезней, проверить себя по карточкам статей, собрать «Дело».
Telegram Mini App `@nll_voenkom_bot`. Ядро поиска (NNL) живёт в репозитории `smworklair/NNL`.

| Папка | Что это |
|---|---|
| `app/` | приложение: Next.js 16, TypeScript, Telegram SDK, SQL (Neon) для «Дела» |
| `карточки/` | карточки 88 статей: данные, сборка, проверка цитат |
| `макеты/` | старый сайт на HTML/JS (пока смотрит старый Mini App) |
| `ядро_api/` | сборка Python-ядра NNL как функции Vercel (`NNL_ROOT=путь/к/клону/NNL python ядро_api/собрать.py`) |

Как всё обновлять и что где живёт: `ПРОДОЛЖЕНИЕ_БЕЗ_НОУТБУКА.md`.
