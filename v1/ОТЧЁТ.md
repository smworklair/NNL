## 3. Алгоритм маршрута (детерминированный, без нейросети)

1. Токенизация: нижний регистр + регулярное выражение слов (кириллица/латиница/
   цифры). Стемминг: правила snowballstemmer-russian (зафиксированный код,
   обучения нет; запасной вариант — обрезка окончаний по списку).
2. Маркеры блоков лежат в паспортах. Построены разностью множеств текстов баз
   знаний (вопросы train/dev/bench НЕ использовались):
   здоровье — заголовок статьи + все пункты + все пояснения (88 документов);
   право — заголовок темы + заголовки норм + начала текстов норм (44 документа).
   Маркер = стем с doc-freq ≥ 2 в своей области и 0 в чужой, длина > 3.
   Итог: маркеров здоровья 985, права 200.
3. Счёт блока = число его маркеров, встреченных в вопросе (по множеству стемов).
   Маршрут: единственный строгий максимум при счёте > 0; ничья или все нули →
   «не знаю» (None). Функция чистая: тот же вопрос + тот же набор паспортов =
   тот же путь всегда. Обученного классификатора и вызовов LLM в маршруте нет.
4. Выбранный блок делает прямой проход MLP; при уверенности < 0.30 (порог из
   паспорта) — «не знаю» с записью в след.

Частота верного выбора блока: **0.794** всего (0.771 здоровье, 0.833 право).

## 4. Устройство блоков

- `блоки/zdorovie`: BoW-MLP 1666→128→88 (ReLU, softmax), **224 728 чисел**,
  словарь из lay_train+teacher-train (своя область), Adam 40 эпох, seed=1.
- `блоки/pravo`: BoW-MLP 1204→128→44, **159 916 чисел**, словарь из lex-train,
  Adam 80 эпох, seed=2.
- Только numpy, с нуля, на CPU (минуты). Словари и веса областей не пересекаются
  по построению (разные файлы, разные обучения). Ответ — первая цитата знания
  по предсказанной метке (дословный текст базы, сеть текст не пишет).
- Паспорт каждого блока: имя, область, тип входа/выхода, зависимости
  («нет, цельная модель»), чем и на чём обучен, метки, маркеры, порог.

## 5. Что не получилось и почему

1. **К2 в строгом виде провален.** Причина — относительное правило максимума:
   удаление конкурента меняет исходы оставшегося блока (ранее проигранные/
   отказные вопросы теперь выигрываются) и пропускает чужие вопросы с
   ненулевым счётом (утечки 10/293 и 58/168, все неверные). Асимметрия утечек
   (0.655 против 0.966) — следствие широких маркеров здоровья (985): медицинские
   слова встречаются и в правовых вопросах (медкомиссия, смешанные
   also_health 24/168). Абсолютный порог (кворум счёта) убрал бы часть утечек,
   но подбирался бы уже по бенчу — делать этого не стал, фиксирую как есть.
2. **Качество здоровья (0.543) заметно ниже права (0.613).** Причины: 88 классов
   против 44 при коротких разговорных парафразах, не покрытых словарём знаний;
   там же слабее маршрут. Это и есть дыра по К3.
3. **Предсказание качества занижено** (0.33–0.43 против факта 0.568): маленькие
   MLP при полном переобучении обобщились лучше моей оценки. Ошибка
   в консервативную сторону, фиксирую.
4. Честная оговорка: вариант источника текстов для маркеров выбирался по двум
   предварительным пробам маршрута на бенче (0.722 против 0.794); сами маркеры
   из вопросов не извлекались, веса на бенче не настраивались, но выбор правила
   видел бенч-числа. Пробы — файлы `probe_route.py`, `probe_route2.py`.
