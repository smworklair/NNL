## Что сделать (по порядку, после каждого пункта короткий отчёт «до → после»)
1. **Один API, одна модель.** Бесплатная квота Alibaba закончилась (`HTTP 403 free quota exhausted`). Не пополняй и не обходи. Переведи **все роли** на одну модель `groq:openai/gpt-oss-120b`: добавь пресет (по образцу пресета `flash` в `диалог.py`, словарь `ПРЕСЕТЫ`) и сделай его значением по умолчанию (`NNL_ПРЕСЕТ`). Учти лимит Groq 8000 токенов в минуту на модель: в `клиент.py` уже есть ожидание при лимитах; не раздувай запросы, проверь, что живой диалог не упирается в лимит на 7–10 репликах.
2. **Живой диалог целиком.** Запусти два сценария из `README` (`readme.md`, раздел «Сквозной сценарий») через `диалог/диалог.py`, затем те же через сервер (`python -X utf8 -I диалог/сервер.py 8091`, свой порт; порт 8090 у пользователя не трогать, процесс его не убивать). Ожидание: сценарий 1 → ст. 34, пункт «в», категория В; сценарий 2 («сам решил, что минус семь») → категорию не называет. Затем ещё 6 разных сценариев своих (диагноз без врача, поправка «не врач, а я сам», чужая болезнь, посторонняя реплика, число на границе 6,0, просьба об итоге без фактов). Для каждого покажи: вход, ответ, `решение_кода`, сработала ли охрана «рассказчик разошёлся с кодом». Найденные ошибки чини, не меняя логику решения.
3. **Два упавших теста защиты.** `диалог/тест_защиты_диалога.py` даёт 26 из 28: проверки 24 («ложное „врач“») и 26 («это у брата») требуют, чтобы замороженный вариант «до» (`NNL/каскады/до/`) был плохим (98 % и 90 %+), а теперь он даёт 28 % и около того. Выясни, почему изменилась точка отсчёта (какая общая правка повлияла на «до»). Если «после» по-прежнему в пределах порогов, обнови сравнение честно: пересними «до» из замороженных копий или опиши в тесте, что именно считать базой. **Нельзя** ослаблять пороги «после». Покажи числа до и после правки теста.
4. **Описание задачи на сайте.** В `диалог/стенд.html` (файл читается страницей при каждом открытии; в CRLF, правь скриптом с проверкой, что якорь найден ровно один раз; сначала положи копию `стенд_до_описания.html`) добавь над диалогом одну строку: «Задача: по словам человека находит статью Расписания болезней и называет категорию годности только при подтверждении врача». 5. **Финальный прогон бенча.** `python -X utf8 -I диалог/прогон_шести.py --режимы код --тесты 1,2,3 --прогонов 3 --метка финал_123` и отдельно тесты 4,5 с `--модель groq:openai/gpt-oss-120b --прогонов 3 --метка финал_45`. ## Ловушки среды (Windows, оболочка Bash)
- Кириллические имена переменных в bash недопустимы: используй ASCII (`DST=...`).
- Обратные слэши в heredoc схлопываются: скрипты правок с кириллицей и слэшами пиши файлом (не heredoc) и запускай `python -X utf8 файл.py`.
- Флаг `python -I` отключает `PYTHONPATH`: для тестов, которым нужна папка `NNL/каскады`, запускай без `-I`.
- Файлы проекта часть в CRLF; не меняй окончания строк.
- Запуск Python: `-X utf8` и `PYTHONIOENCODING=utf-8`.
