# Замер: NNL против флагманов

Проверка, насколько NNL (ядро v6 + блоки) уступает флагманам (Claude, GPT, Grok и другим) или обходит их на одних и тех же
живых вопросах призывников. **Это предварительный замер:** эталон — разметка ИИ (Claude, Muse Spark), а не эксперта.

v6, `внешние`, `v7_якоря` и рабочий проект только читаются. Всё пишется в эту папку.

## Что уже сделано

- **Набор** — 600 вопросов: свежие (200, разметка Claude), свежие2 (200, две разметки: Claude и Muse Spark),
  свежие3 (200, Muse Spark). Тексты — те же, что видят системы NNL в замерах агентов. `набор/набор.jsonl`, sha256 `b7af2ca5…`.
- **NNL посчитан** (системы В2б и Д). Цифры совпадают с замерами агентов один в один — счёт проверен.
- **Предсказание для флагманов** записано до запуска: `ПРЕДСКАЗАНИЕ.md`, sha256 в `ПРЕДСКАЗАНИЕ.sha256`.
- **Флагманы ещё не запускались**: на этом компьютере нет ключей API и пакетов `anthropic`/`openai`.

## Как запустить флагманов

### Через API — все 600 вопросов

1. `pip install anthropic openai`
2. Ключи — только в переменные окружения (не в чат и не в файлы): `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `XAI_API_KEY`.
3. Проба на одной пачке (10 вопросов, копейки): `python -I прогон.py --провайдер anthropic --модель claude-opus-5-5 --предел 1`
4. Полный прогон — та же команда без `--предел`. Оценка для Claude Opus 5.5 — $3–8.
   Claude Fable 5.1 (самая сильная модель Anthropic): `--модель claude-fable-5-1`, примерно в 2,5 раза дороже.
5. GPT и Grok: `--провайдер openai` или `--провайдер xai`, `--модель <имя флагмана из документации провайдера>`, `--имя gpt` / `--имя grok`.
   Другие API, совместимые с OpenAI: `--провайдер совместимый --адрес <base_url> --ключ-переменная <ИМЯ>`.

Прерванный прогон продолжается с места остановки: сырые ответы лежат по пачкам в `сырые/<имя>/`.

### Через OpenCode — модели вашей подписки, без своих ключей

Скрипт `опенкод.py` прогоняет пачки через `opencode run`. Каждая пачка идёт в новую сессию. Модель работает агентом `zamer`
из `опенкод_папка/opencode.json`: у него запрещены все инструменты (файлы, bash, веб), поэтому модель отвечает сама
и не может заглянуть в эталон.

1. Проба на одной пачке: `python -I опенкод.py --модель opencode-go/grok-4.7 --предел 1`
2. Полный прогон (60 пачек): та же команда без `--предел`. Быстрее — `--потоков 3`.
3. Повышенное усилие рассуждения, если модель его поддерживает: `--вариант high`.
4. Только 60 вопросов ручной выборки: `--выборка`.

Бесплатные модели `opencode/…` через `opencode run` не работают: сервер отвечает «free tier can only be used from within
OpenCode». Нужны модели подписки `opencode-go/…`, список: `opencode models`.
Muse Spark размечал свежие2 и свежие3, поэтому на своей разметке он в выигрыше: смотрите срез «свежие · Claude».

### Вручную через чаты — бесплатно, 60 вопросов

В `ручной/` уже лежат `пачка_01.txt` … `пачка_06.txt` (по 10 вопросов, выборка общая для всех чатов).
Для каждой пачки откройте новый чат (лучше без веб-поиска и памяти), вставьте текст целиком, а ответ сохраните в файл
`ручной/chatgpt_01.txt`, `ручной/chatgpt_02.txt` и т. д. Номер в конце имени — номер пачки. Затем:
`python -I ручной.py импорт --имя chatgpt_веб ручной/chatgpt_*.txt`

### Оценка

`python -I оценка.py` → `результаты/таблица.md`. Ручные замеры дополнительно сравниваются со всеми системами на своей выборке.

## Показатели

- **область верна** — названа одна из допустимых областей («не знаю» у NNL = «вне»);
- **здоровье: статья**, **право: тема** — верная статья Расписания болезней или правовая тема из эталона;
- **вне → вне** — вопрос не про призыв, система его не взяла;
- **уверенных ошибок** — система назвала статью или тему, и она неверна. Для призывника это самое опасное;
- **отказ модели** — модель отказалась отвечать; считается как «не знаю».

## Правила честности

- Всем системам даётся одно и то же: определения областей, закрытый список (88 статей, 44 темы) и вопросы.
  Флагманам, как и NNL, разрешено отвечать «не знаю».
- Разметку делали ИИ. Claude разметил свежие и свежие2, Muse Spark — свежие2 повторно и свежие3. Модель-разметчик
  в выигрыше на своей разметке, поэтому смотрите срезы по разметчикам и срез «оба согласны».
- Определения областей в запросе написаны по разметке задним числом. Пограничные вопросы флагман может отнести иначе,
  поэтому «спорные» не штрафуются.
- **Ответы флагманов не использовать для обучения блоков.** Иначе дальше мы будем мерить копию флагмана.
- Anthropic: включена подстраховка при отказе (`fallbacks: "default"`). Если ответ выдала подстраховочная модель,
  он засчитывается названной модели как отказ. Выключить: `--без-подстраховки`.
- **Для финального замера нужно другое:** набор, размеченный экспертом (военный юрист, врач ВВК), с учётом изменений
  закона 2023–2024 годов, и вопросы новее данных, на которых обучались флагманы.

## Файлы

| файл | что делает |
|---|---|
| `замер_общее.py` | пути, набор, текст запроса, разбор ответа модели |
| `собрать_набор.py` | собирает `набор/набор.jsonl` из разметок v6 и `внешние` |
| `nnl.py` | ответы систем NNL → `ответы/nnl_*.jsonl` |
| `прогон.py` | флагманы через API → `ответы/<имя>.jsonl` |
| `опенкод.py` | флагманы через OpenCode (`opencode run`) → `ответы/oc_<модель>.jsonl` |
| `опенкод_папка/opencode.json` | агент `zamer` без инструментов для прогона через OpenCode |
| `ручной.py` | выгрузка пачек для чатов и загрузка ответов |
| `оценка.py` | таблица по всем системам и срезам |
| `ПРЕДСКАЗАНИЕ.md` | ожидания до запуска флагманов (не меняется) |
