# README — как воспроизвести (муси_1.3, знание и случайная истина)

Все команды выполняются в этой папке. Проект вне папки только читается.
Данные только выдуманные. Бюджет моделей не больше 600 обращений за всё исследование.

## 1. Сгенерировать кейсы
python3 gen_cases.py

## 2. Запустить эксперимент (две модели Groq, повторы: настройка по 1, тест по 3)
python3 run_exp.py

## 3. Посчитать метрики только по тестовой половине
python3 analyze.py

## 4. Красный тест (заведомо плохая реализация, без обращений к моделям)
python3 test_red.py

## Файлы
- ВОПРОС.md — вопросы, определение обоснованного вердикта, порог провала.
- gen_cases.py — генерация 44 выдуманных кейсов по статье 34.
- кейсы.json — сгенерированные кейсы (порождается командой 1).
- run_exp.py — досье трёх вариантов, промт системы из проекта, вызовы через клиент.
- промт_итога.txt — точный системный промт, сохранённый при запуске.
- сырые_ответы.jsonl — сырые ответы моделей (порождается командой 2).
- analyze.py — извлечение категории, S, R, верность, интервалы Уилсона.
- test_red.py — проверка, что метрика краснеет на плохой реализации.
- ОТЧЁТ.md — итог (пишется в конце).
