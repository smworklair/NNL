# Исследование: Агент-«детектив» против режима «Ядро ведёт» в NNL

Исследовательская папка: `C:\ЯДРО-ОПЫТ\исследования\gemini_3.8\`

## Описание проекта и аспекта
В проекте NNL штатно применяется архитектура «Ядро ведёт»: математическое ядро управляет байесовским состоянием 88 статей Расписания болезней (ПП РФ № 565), определяет порядок уточняющих вопросов по информационному выигрышу и контролирует безопасность вывода (охрана чисел, запрет вердикта по категории при отсутствии подтверждения врача, только графа I).

В данном исследовании изучена инверсия управления («Агент-детектив»): языковая модель сама управляет процессом через механизм вызова инструментов (tool calling: классификаторы NNL, база Расписания, диалог с призывником), а ядро выступает лишь внешним арбитром/валидатором готового ответа. Измерена реальная цена принятого безопасного ответа (с учётом брака, промежуточных шагов инструментов и штрафных перегенераций).

## Структура файлов в папке
- `ВОПРОС.md` — формулировка исследовательского вопроса и порог провала (критерий фальсификации).
- `клиент_агента.py` — клиент с поддержкой OpenAI-совместимых инструментов (tool calling), пула моделей, локального кэширования (`кэш_агента.jsonl`) и обработки лимитов 429.
- `данные_кейсы.py` — синтетический набор из 24 выдуманных историй призывников с разделением на обучающую и тестовую выборки строго по хешу `sha256(id) % 2`.
- `валидатор.py` — арбитр безопасности и точности ядра NNL (охрана чисел, проверка категории годности, соответствие статье).
- `тест_валидатора_падает.py` — модульные тесты валидатора ядра на отсечение галлюцинаций чисел и незаконных категорий.
- `тест_краснеет.py` — демонстрация падающего (красного) теста на заведомо небезопасной наивной реализации (код возврата 1).
- `режим_ядро.py` — реализация штатного режима NNL («Ядро ведёт»).
- `режим_агент.py` — реализация автономного агента-детектива с циклом вызова инструментов и валидацией ядра.
- `эксперимент.py` — полный воспроизводимый прогон сравнения обоих режимов на тестовой выборке с динамическим расчётом метрик.
- `расчёт_результатов.py` — динамический расчёт статистических показателей, доверительных интервалов и коэффициентов сравнения.
- `ОТЧЁТ.md` — итоговый научный отчёт по исследованию.

## Команды для воспроизведения

### 1. Проверка защитных механизмов валидатора ядра
```powershell
python тест_валидатора_падает.py
```

### 2. Демонстрация краснеющего теста (падение на наивной реализации)
```powershell
python тест_краснеет.py
```
*(Завершается с кодом возврата 1 и сообщением AssertionError о блокировке вердикта).*

### 3. Проверка разбиения данных по хешу (50% train / 50% test)
```powershell
python данные_кейсы.py
```

### 4. Динамический расчёт сравнительных метрик и доверительных интервалов
```powershell
python расчёт_результатов.py
```

### 5. Запуск основного экспериментального пайплайна
```powershell
python эксперимент.py
```
*(Все обращения к LLM кэшируются в `кэш_агента.jsonl`, результаты сохраняются в `результаты_эксперимента.json`).*
