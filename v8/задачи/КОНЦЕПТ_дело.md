# Концепт: «Дело» как лестница доказательств (набросок, 20.10.2026)

## Идея одной фразой
Дело — это не список закладок, а набор **утверждений о человеке**, у каждого из которых есть **уровень доказанности**. Задача приложения — поднимать каждое утверждение на ступень выше и всегда знать, что делать дальше. Главная «следовательская» вещь — переключатель **«Глазами комиссии»**: он показывает дело таким, каким его увидят в бумагах, без слов на веру.

## Почему это про NNL
Ядро уже живёт по этому правилу: без подтверждения врача категорию не называет, у улики есть потолок, слова человека и документ весят по-разному. Дело превращает внутреннее правило ядра в понятный человеку интерфейс. Это не ещё одна справка, а то, чего нет у обычного чата: он не отличает «я так думаю» от «есть бумага».

## Лестница доказательств (четыре ступени)
1. **Со слов** — человек сказал. Для комиссии этого нет.
2. **Есть документ** — выписка, заключение, результат обследования на руках.
3. **Подано** — документ передан в военкомат (дата, способ, отметка о принятии).
4. **Принято** — военкомат принял, есть отметка, документ приобщён к личному делу.

Каждое утверждение («гипертоническая болезнь», «миопия −7», «сколиоз») идёт по этой лестнице отдельно. Ступени 2–4 подтверждаются отметкой человека (+ фото или номер документа, по желанию).

## «Глазами комиссии»
Переключатель вверху экрана. В обычном виде видно всё дело. В режиме «Глазами комиссии» всё, что на ступени «со слов», гаснет и подписано «в деле не учитывается». Остаётся то, что подтверждено бумагой. Счётчик меняется (было 3 факта, видно 1), а ниже одна строка: что нужно, чтобы следующий факт стал виден (например, получить выписку, и кнопка бланка).
Важно: это не прогноз решения комиссии. Режим показывает только то, что есть в бумагах. Так и подписывается на экране.

## Остальные части дела
- **Хронология с «белыми пятнами».** Повестка, медосвидетельствование, решение, сроки. Пропуски подсвечиваются («нет даты решения»). Даты вводит человек, ядро их не извлекает.
- **Журнал обращений.** Каждое обращение в военкомат: дата, кто, что сказали, результат. Из журнала одним нажатием собирается хронология для жалобы (бланк «На действия или бездействие сотрудника военкомата» с подставленными фактами).
- **Противоречия.** Ядро сверяет утверждения друг с другом и со словами человека («сам решил» против «врач подтвердил»). Показывает не как обвинение, а как «проверьте».
- **Следующий шаг.** Одно действие по состоянию дела: нет документа → собрать; есть → отнести; не приняли → жалоба. Решает набор правил, нейросеть не нужна.

## Кто что делает
| Что | Кто |
|---|---|
| Находит статью по словам, задаёт вопросы | Блоки NNL и ядро (уже есть) |
| Определяет пункт по числам (ст. 34, 40, 86, 13) | Код по порогам из текста статьи (уже есть) |
| Подставляет факты в бланк | Код, шаблоны «Бумаг» (уже есть) |
| Выбирает следующий шаг по состоянию дела | Правила (нужно написать) |
| Ставит даты, сроки обжалования | Человек вводит, юрист проверяет правила |
| Хранит дело | Телефон человека (localStorage), экспорт в файл |

## Модель данных (черновик)
```
дело = { версия, профиль: {возраст?, этап?},
  утверждения: [ {ид, статья?, текст, ступень: 1..4, документы: [{название, дата?, заметка?}]} ],
  хронология: [ {дата, событие, источник} ],
  обращения: [ {дата, куда, что_сказали, результат} ] }
```
Всё необязательное, ничего не отправляется на сервер.

## Этапы
1. **Утверждения и лестница + «Глазами комиссии»**, хранение в браузере. Это ядро идеи, его можно показать.
2. Хронология и журнал обращений.
3. Сборка жалобы из журнала.
4. Сохранить и загрузить дело файлом.
5. Позже, отдельным решением: сервер и аккаунт (персональные данные о здоровье, нужны согласие и защита).

## Риски и открытое
- Данные о здоровье призывника: по умолчанию только на устройстве; скрытые отметки (ВИЧ и т. п.) оставить как сейчас.
- «Комиссия учтёт» нельзя подавать как обещание. Формулировка только «видно в бумагах».
- Сроки и порядок подачи документов проверяет юрист, до этого их в приложении нет.
- Как фиксировать ступень «принято»: только отметка человека или ещё фото документа с отметкой.
