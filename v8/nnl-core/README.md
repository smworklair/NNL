# nnl-core

**NNL (Neural Network Lego)**: независимые блоки, общая шина понятий, два такта, ядро согласованности и селективный решатель. Чистое ядро без предметной области:
всё предметное (данные, веса, словари, приложение) живёт в блоках и в приложении над ядром.

```
текст → язык → [такт 1: блоки по одному, шина пуста] → уверенные выводы пишутся на шину
      → [такт 2: блоки, читающие шину, уточняются] → ядро проверяет согласованность → решатель: ответ или «не знаю»
```

## Что внутри
| Файл | Что делает |
|---|---|
| `nnl/матплата.py` | слоты, паспорта и sha256 весов, шина с происхождением значений, конфликты (спор «да»/«нет» убирает понятие из срезов), изоляция такта 1 |
| `nnl/процессор.py` | диспетчер двух тактов для любого числа блоков; без `if имя == …`; необязательный `предел_влияния` |
| `nnl/ядро.py` | проекции ответов блока в понятия шины (из паспорта), проверка цепочки без знания смысла пространств имён |
| `nnl/решатель.py` | ответ или воздержание по порогу уверенности; слепого argmax нет |
| `nnl/линтер.py` | проверка блока и **проверка вставки** блока в работающую систему (соседи меняются ≤ ε, такт 1 не меняется, снятие возвращает как было) |
| `nnl/создать_блок.py` | блок из размеченных фраз за один вызов (хэш-признаки, numpy) |
| `nnl/язык.py` | простейший язык: слова и пары слов |
| `архитектуры/мешок_шина.py` | эталонная архитектура блока; `игрушка_арх.py` — игрушечная |
| `примеры/игрушка.py` | мир из 3–60 независимых блоков для опытов с шиной |
| `примеры/своя_система.py` | своя система за 30 строк |
| `СТАНДАРТ_БЛОКА.md` | контракт блока: паспорт, функции архитектуры, шина, проверка вставки |

## Быстрый старт
```bash
python -X utf8 тесты/тест_ядра.py        # 19 проверок, сеть не нужна
python -X utf8 примеры/своя_система.py   # две системы за 30 строк
```
Нужны только Python 3 и numpy.

## Как собрать новую систему
1. Разметьте фразы по ответам блока (`[(текст, ответ), ...]`).
2. `создать_блок(папка, имя, примеры, проекции={...}, читает=[...])` — получаете папку блока (паспорт + веса).
3. `python -m nnl.линтер <папка_блока>` — проверка паспорта, весов и архитектуры.
4. Подключите к матплате и проверьте вставку: `линтер.проверить_вставку(процессор, папка_блока, вопросы)`.

## Принципы (нельзя нарушать)
1. На такте 1 срез шины любого блока пуст `{}` (Lego-индекс 0).
2. В процессоре и ядре нет имён блоков и предметной области.
3. Решение — только через решатель с порогом уверенности.
4. Новый блок проходит проверку вставки до подключения.
