# Архив

Здесь лежат версии ядра, которые больше не развиваются. Нужны, чтобы:

* посмотреть, как система выглядела раньше (идеи, числа, замеры);
* взять оттуда кусок в новую работу;
* понять, почему в новой версии сделано не так, а так.

**Что не развивается.** Код в этих папках не запускается как часть текущего проекта: в нём остались пути к прежним именам папок (`v6`, `bench`, `v4`), а часть скриптов ссылается на данные из внешнего проекта (`C:\ВОЕНКОМАТ ПРОЕКТ…`), которых в этом репозитории нет.

**Что работать может** — после проверки: `архив/ядро_v6/реальные/*.jsonl` используются как тест-наборы в `система/замер/общее.py`, а `архив/ядро_v4/стандарт/` и `архив/ядро_v6/данные/` — как источники корпусов.

## Что внутри

| Папка | Что это | Когда было актуально |
|---|---|---|
| `v1_первая_версия/` | самая первая сборка: ядро, обучение блоков, два обученных блока (здоровье, право), отчёт | v1 |
| `ядро_v4/` | первое полноценное ядро: ядро, архитектуры, типы, обучение блоков, GSM8K/MGSM | v4 |
| `ядро_v5/` | то же с блоками приложения и калибровкой порогов | v5 |
| `ядро_v6/` | блоки «право.знание», пулы разметки, отложенные тексты | v6 |
| `nnl_core_v8/` | первый пакет ядра как библиотеки (`nnl/`), предшественник нынешнего `NNL/` | v8 |

Историю этих версий целиком смотрите в `git log` по соответствующим папкам.
