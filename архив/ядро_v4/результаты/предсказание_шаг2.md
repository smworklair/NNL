## Шаг 2. Предсказание (записано ДО обучения блоков шага 2)

Устройство. Каждый блок сам принимает `общие:Запрос` и состоит из двух маленьких сетей:
- «ответ» — мешок признаков (основы, пары основ, куски слов 3–5 букв по хешу) → классы своей области;
- «заявка» — «моё или фон», обучена на своих вопросах против стандартного фона.

Фон: `стандарт/фон_train.jsonl` — 12 000 текстов (по 4000 заголовков новостей, отзывов и научных аннотаций).
Ядро берёт наибольшую заявку не ниже 0,5. Блоки «здоровье» и «право» обучаются первыми. Блок «команды»
(голосовые команды MASSIVE, 60 намерений) обучается отдельно и вставляется последним; первые два не переобучаются.

Измеритель `измеритель/шаг2.jsonl`: общий bench (293 вопроса здоровья + 168 права) + 1000 команд из теста MASSIVE.

| что | ожидаю | диапазон |
|---|---|---|
| здоровье + право до вставки, доля верных | 0,73 | 0,68–0,77 |
| вопросы здоровья/права, ушедшие не в свой блок | 3 % | 1–6 % |
| «не знаю» на вопросах своей области (все заявки < 0,5) | 2 % | 0–5 % |
| **после вставки «команд»: изменилось ответов здоровья и права** | **≤ 1 %** | 0–3 % |
| команды: доля верных | 0,78 | 0,70–0,85 |
| команды, ушедшие в здоровье/право | 2 % | 0–5 % |

Успех шага (из `ПЛАН.md`): после вставки изменилось ≤ 2 % ответов здоровья и права, а команды работают.
Провал: изменилось больше 2 % — значит, вставка ломает старые области.
