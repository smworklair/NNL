# Исследование: Числа как источник выдумок

## Вопрос

Какие классы выдумок и искажений чисел ловятся детерминированными методами (без языковой модели), а какие нет, и какой у каждого класса порог провала?

## Как воспроизвести

```bash
cd C:\ЯДРО-ОПЫТ\исследования\kimi_2.7_code
python лаба_числа.py
```

Скрипт не делает обращений к LLM. Результаты сохраняются в `результаты_числа_проектная_охрана.json` и `результаты_числа_расширенная_охрана.json`.

## Тест, который умеет падать

```bash
python тест_падает.py
```

Ожидаемый результат — `AssertionError`: заведомо плохая реализация пропускает выдуманное число.

## Что проверяется

1. **Прямая выдумка**: число с единицей, которого нет в документе.
2. **Прямая выдумка с неизвестной единицей**: число с единицей, не входящей в жёсткий список охраны.
3. **Производное значение**: арифметика над документными числами.
4. **Неправильный контекст**: число из документа, но применено к другой ситуации.
5. **Число словами**: «три месяца» вместо «3 месяца».
6. **Легитимное число**: документное число, использованное корректно.

## Режимы

- **проектная_охрана**: точно такой же паттерн единиц, как в `NNL/диалог/диалог.py`.
- **расширенная_охрана**: любая буквенная/символьная единица после числа.
