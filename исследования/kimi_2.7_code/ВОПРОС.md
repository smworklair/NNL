# Исследовательский вопрос

## Выбранный вопрос

Какие классы выдумок и искажений чисел ловятся детерминированными методами (без языковой модели), а какие нет, и какой у каждого класса порог провала?

## Классы искажений чисел

1. **Прямая выдумка числа** — модель называет число, которого нет в документе и не сказал человек.
2. **Вычисленное/производное значение** — модель складывает, умножает или иначе вычисляет число из документа.
3. **Число из правильного документа, но неправильный семантический контекст** — число есть в Расписании, но применено к другой статье или ситуации.
4. **Число написано словами** — «три месяца» вместо «3 месяца».

## Порог провала

Для каждого класса зафиксировать:

- Доля выдумок, пойманных детерминированным фильтром.
- Доля ложных срабатываний (когда правильное число отмечено как выдумка).
- Что именно сломалось: единица измерения, контекст, синоним, арифметика.

Если какой-то класс ловится менее чем в 80 % случаев, это порог провала: нужен другой метод (вероятностный, семантический, с LLM).
