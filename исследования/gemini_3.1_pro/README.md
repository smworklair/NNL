# Исследование: Симметрии и инварианты в NNL

Исследовательский проект по проверке устойчивости языковых моделей к преобразованиям входа и их трансляции в математическое ядро NNL (Расписание болезней, ПП РФ № 565 в редакции 2026 года).

---

## Структура файлов

* `ВОПРОС.md` — исследовательские вопросы, гипотезы, классы преобразований (инвариантные и контрастные), критерии нарушений и пороги провала (фальсификации).
* `данные.py` — детерминированный генератор 40 синтетических медицинских кейсов с хеш-разбиением (`sha256(case_id) % 2`) на выборку настройки (TRAIN, 24 кейса) и контрольную выборку (TEST, 16 кейсов). Реальные персональные данные отсутствуют.
* `оценка.py` — функции сквозной оценки: извлечение фактов LLM, прогон через математическое ядро (`расследование.Расследование` + `блоки.Блоки`), расчёт доверительных интервалов Вильсона (95% ДИ).
* `контроль_падения.py` — контрольный тест падения (Red Test): запуск заведомо дефектного разборщика (наивный словарный поиск с потерей отрицаний, чисел и источника) для верификации чувствительности тестового стенда.
* `эксперимент.py` — основной сценарий тестирования моделей (`openai/gpt-oss-20b`, `qwen/qwen3.8-27b`) через клиент NNL с кэшированием запросов и сохранением детальных JSON-отчётов.
* `ОТЧЁТ.md` — итоговый научный отчёт с полными командами, выводом терминала, статистическими результатами и предложениями для NNL.

---

## Команды для воспроизведения

Все команды запускаются из корня репозитория `C:\ЯДРО-ОПЫТ\` с указанием кодировки UTF-8:

### 1. Запуск контрольного теста падения (Red Test)
```powershell
python -X utf8 C:\ЯДРО-ОПЫТ\исследования\gemini_3.1_pro\контроль_падения.py
```
*Ожидаемый результат*: код возврата 0, средний уровень критических ошибок $>80\%$, подтверждение валидности метрик.

### 2. Запуск эксперимента для слабой модели (`openai/gpt-oss-20b`)
```powershell
python -X utf8 C:\ЯДРО-ОПЫТ\исследования\gemini_3.1_pro\эксперимент.py --модель openai/gpt-oss-20b --выборка test
```

### 3. Запуск эксперимента для базовой модели (`qwen/qwen3.8-27b`)
```powershell
python -X utf8 C:\ЯДРО-ОПЫТ\исследования\gemini_3.1_pro\эксперимент.py --модель qwen/qwen3.8-27b --выборка test
```

### 4. Комплексный запуск и сравнительный анализ
```powershell
python -X utf8 C:\ЯДРО-ОПЫТ\исследования\gemini_3.1_pro\эксперимент.py --модель обе --выборка test
```
Команда запускает обе модели на контрольной выборке TEST, сохраняет `результаты_openai_gpt-oss-20b_test.json` и `результаты_qwen_qwen3.8-27b_test.json` и выводит сравнительную таблицу нарушений на уровне фактов и ядра.
