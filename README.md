# ЯДРО-ОПЫТ

**NNL** (Neural Network Lego) — модульная архитектура для сборки специализированных нейросетевых блоков через общую шину данных и двухтактовую диспетчеризацию.

Смысл проекта — не предметная область, а **архитектура**: как из независимых блоков собрать систему, которая не врёт и не ломается каскадно. Предметная область (медицина и право) — только стенд, на котором это проверяется.

---

## Три части репозитория

| Что | Где | Состояние |
|---|---|---|
| **Ядро** — архитектура NNL | `NNL/` | в разработке |
| **Система** — работающая сборка на старом ядре | `система/` | работает, кормит диалог |
| **Лаборатория** — пробы нового ядра | `лаборатория/` | активная разработка |

Раньше всё это лежало в корне под именами `v4`…`v9.8.1` и было непонятно, что из этого живое. Теперь роль каждой папки видна по имени.

## Карта папок

## Как запустить

```bash
# тесты архитектуры (сети не нужно)
python -X utf8 NNL/тесты/тест_системы.py
python -X utf8 NNL/тесты/тест_защиты.py
python -X utf8 NNL/диалог/тест_следа.py
python -X utf8 NNL/диалог/тест_защиты_диалога.py

# стенд диалога (свой порт — 8090 занят)
python -X utf8 NNL/диалог/сервер.py 8091

# живой диалог в терминале
python -X utf8 NNL/диалог/диалог.py "текст реплики" ...

# проверить блок и безопасность его вставки
python -X utf8 NNL/линтер.py система/блоки/основная_внешние.з1/здоровье
python -X utf8 NNL/линтер.py система/блоки/основная_внешние.з1/здоровье --вставка система/блоки/основная_внешние.з1/право

# стенды каскадных ошибок
python -X utf8 NNL/каскады/стенд_шины.py --профиль после
python -X utf8 NNL/каскады/стенд_диалога.py --профиль после
```

Подробности — в [`NNL/README.md`](NNL/README.md) и [`NNL/СТАНДАРТ_БЛОКА.md`](NNL/СТАНДАРТ_БЛОКА.md).
