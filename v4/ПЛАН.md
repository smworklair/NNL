# v4 — общее ядро + сменные блоки-знания

Цель: ядро одно на все задачи, без ИИ. Блок — отдельная модель-знание: вставил — система знает область,
вынул — не знает, остальные не заметили. Блоки двух видов: «выбор» (военкомат: id из своего списка) и
«писатель» (задачи: решение текстом по шагам). Бюджет ≈10 млн чисел, если нужно — больше.
v3 (`C:\ЯДРО-ОПЫТ\v3`) не трогается — запасной.
