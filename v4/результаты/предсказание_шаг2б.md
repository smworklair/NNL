## Шаг 2. Предсказание (записано ДО обучения блоков шага 2)

Устройство. Каждый блок сам принимает `общие:Запрос` и состоит из двух маленьких сетей:
- «ответ» — мешок признаков (основы, пары основ, куски слов 3–5 букв по хешу) → классы своей области;
- «заявка» — «моё или фон», обучена на своих вопросах против стандартного фона.

Фон: `стандарт/фон_train.jsonl` — 12 000 текстов (по 4000 заголовков новостей, отзывов и научных аннотаций).
Ядро берёт наибольшую заявку не ниже 0,5. Блоки «здоровье» и «право» обучаются первыми. Блок «команды»
(голосовые команды MASSIVE, 60 намерений) обучается отдельно и вставляется последним; первые два не переобучаются.

Измеритель `измеритель/шаг2.jsonl`: общий bench (293 вопроса здоровья + 168 права) + 1000 команд из теста MASSIVE.

| что | ожидаю | диапазон |
|---|---|---|
| здоровье + право до вставки, доля верных | 0,73 | 0,68–0,77 |
| вопросы здоровья/права, ушедшие не в свой блок | 3 % | 1–6 % |
| «не знаю» на вопросах своей области (все заявки < 0,5) | 2 % | 0–5 % |
| **после вставки «команд»: изменилось ответов здоровья и права** | **≤ 1 %** | 0–3 % |
| команды: доля верных | 0,78 | 0,70–0,85 |
| команды, ушедшие в здоровье/право | 2 % | 0–5 % |

Успех шага (из `ПЛАН.md`): после вставки изменилось ≤ 2 % ответов здоровья и права, а команды работают.
Провал: изменилось больше 2 % — значит, вставка ломает старые области.

## Шаг 2. Результат (после предсказания; раздел выше не менялся — `результаты/предсказание_шаг2.sha256`)

Блоки: здоровье, право, команды — по 1,7 млн чисел, каждый обучен отдельно (`обучение/обучить_блок_области.py`).

| что | предсказал | вышло |
|---|---|---|
| здоровье + право до вставки | 0,73 (0,68–0,77) | 0,722 (здоровье 0,730, право 0,708) |
| вопросы здоровья/права в чужой блок | 3 % (1–6) | 0,2 % (1 из 461) |
| «не знаю» на своих вопросах | 2 % (0–5) | 1,7 % (8 из 461) |
| **после вставки «команд»: изменилось ответов здоровья и права** | ≤ 1 % (0–3) | **0,4 % (2 из 461)** |
| команды: доля верных | 0,78 (0,70–0,85) | 0,805 |
| команды в чужой блок | 2 % (0–5) | 1,2 % |

Контроль ядра при вставке (контрольные наборы блоков): здоровье — изменился 1 ответ из 60, право — 1 из 60.
Файлы весов здоровья и права не менялись. **Критерий успеха шага 2 выполнен: вставка новой области почти не трогает старые.**

**Слабое место — снятие.** Пока нужный блок на месте, он перебивает чужие заявки. Если его снять, его вопросы
часть других блоков забирает себе:

| снят | его вопросы → «не знаю» | его вопросы → ответ чужого блока (неверный) |
|---|---|---|
| здоровье | 238 из 293 (81 %) | 55 (19 %): право 30, команды 25 |
| право | 98 из 168 (58 %) | 70 (42 %): здоровье 44, команды 26 |
| команды | 774 из 1000 (77 %) | 226 (23 %): право 163, здоровье 63 |

Причина: заявка обучена «моё против фона» (новости, отзывы, аннотации). О соседних областях блок ничего не знает,
поэтому на вопрос-чужака иногда отвечает «моё»: например, заявка права ≥ 0,5 на 19 % голосовых команд.
Знание действительно уходит вместе с блоком (ответов снятой области — 0), но вместо «не знаю» система иногда
отвечает чужим блоком.

## Шаг 2б. Починка снятия — предсказание (ДО обучения)

Причина утечки — узкий фон: блоки не видели обычных коротких вопросов и бытовых фраз и путали «вопрос вообще» с «моим».
Фон v2 (`стандарт/фон2_*.jsonl`, зафиксирован до обучения): прежние 12 000 текстов + 15 000 вопросов людей с Яндекс Кью
(CC0, без вопросов о призыве) + 15 000 коротких фраз Tatoeba. Сеть заявки чуть больше (2^15 корзин × 16).
Ядро, сети ответа, данные областей — без изменений. Блоки обучаются заново, каждый отдельно, в `блоки_ф2/`.

| что | ожидаю | диапазон |
|---|---|---|
| снят блок → его вопросы ушли к чужому блоку: здоровье / право / команды | 5 % / 10 % / 8 % | ≤ 10 / ≤ 20 / ≤ 15 |
| «не знаю» на своих вопросах (все блоки на месте) | 3 % | ≤ 6 % |
| вставка «команд»: изменилось ответов здоровья и права | ≤ 1 % | ≤ 2 % |
| доля верных: здоровье+право / команды | 0,72 / 0,80 | ±0,03 |

Успех: утечка при снятии ≤ 10 % по каждой области, остальное не хуже шага 2 более чем на 2 п.п.
